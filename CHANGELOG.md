\# Changelog



\## v1.0.0 — Initial Release

\### Released: 2026-05-25



This is the first full public release of \*\*Osu Save\*\*.



\### ✨ Features

\- Download most‑played beatmaps from any osu! profile

\- Multi‑threaded downloads (1–16 threads)

\- Mirror failover (osu.direct → chimu.moe → nerinyan)

\- Mirror priority settings window

\- Auto‑import downloaded `.osz` files into osu!

\- Integrity checker for existing `.osz` files

\- Automatic re-download of corrupted beatmaps

\- Manifest sync (removes missing files)

\- Retry failed downloads

\- Check for updates (GitHub API)

\- Clean dark UI inspired by osu!lazer

\- Uses your `Osu\_Save.ico` as the app icon



\### 🛠 Technical

\- Thread-safe logging

\- Unified progress bar for all operations

\- Versioning system added (`APP\_VERSION`)

\- GitHub repo binding (`MisterThs/Osu-Save`)
